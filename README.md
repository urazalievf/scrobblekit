# ScrobbleKit

A personal, open-source Apple Music scrobbler that sends every listen to both
[Last.fm](https://www.last.fm) and [ListenBrainz](https://listenbrainz.org).

Planned targets:

- **macOS menu bar app**: captures plays from Music.app in real time.
- **iOS companion app**: captures plays within what Background App Refresh and
  MusicKit polling allow. That is not every play.

Shared logic lives in the `ScrobbleCore` Swift package.

## Status

Early development. Nothing here scrobbles yet.
